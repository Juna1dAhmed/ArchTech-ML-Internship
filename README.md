## 📊 Project Details

### Month 1 Tasks

#### 📧 Task 1: Email Spam Classification
* **Objective:** Build a machine learning model to classify emails as "spam" or "not spam" using a labeled dataset.
* **Methodology:**
    * Preprocessed email text data and extracted important features.
    * Trained a classifier to accurately identify spam emails.
    * Evaluated model performance metrics.

#### 🔢 Task 2: MNIST Digit Recognition
* **Objective:** Use the MNIST dataset of handwritten digit images to build a model that classifies digits from 0 to 9.
* **Methodology:**
    * Preprocessed image data.
    * Trained a model (Neural Network/SVM) to identify digits correctly.
    * Evaluated accuracy on test data.

### Month 2 Tasks

#### 🏠 Task 3: Housing Price Prediction
* **Objective:** Build a model to predict house prices using the **California Housing dataset**.
* **Features Used:** Location, number of rooms, population, and other relevant attributes.
* **Methodology:**
    * Data cleaning and feature selection.
    * Training a regression model to predict prices.
    * Evaluating accuracy and error metrics.

#### 🌸 Task 4: Iris Flower Classification
* **Objective:** Classify Iris flowers into their respective species.
* **Features Used:** Petal length, petal width, sepal length, and sepal width.
* **Methodology:**
    * Data preprocessing.
    * Training a classification model.
    * Evaluating the model's ability to distinguish between species.
